## 核心架构一览

Claude Code 采用分层架构设计：

```
┌─────────────────────────────────────────┐
│              CLI 入口层                   │  main.tsx (Commander.js)
├─────────────────────────────────────────┤
│              初始化层                     │  setup.ts, context.ts
├─────────────────────────────────────────┤
│              UI 层                       │  screens/ + components/ (React + Ink)
├─────────────────────────────────────────┤
│              交互层                      │  hooks/ (100+ React Hooks)
├─────────────────────────────────────────┤
│              引擎层                      │  QueryEngine + query.ts
├─────────────────────────────────────────┤
│         工具层 + 命令层                   │  47 工具 + 80+ 命令
├─────────────────────────────────────────┤
│              服务层                      │  Compact, Token, MCP, API, Voice...
├─────────────────────────────────────────┤
│              基础设施层                   │  Ink 渲染引擎, State, Keybindings...
└─────────────────────────────────────────┘
```

## 技术亮点

1. **自研终端渲染引擎**: 基于 react-reconciler 的 Ink 引擎，支持双缓冲、Yoga 布局、终端协议
2. **编译期特性开关**: 90+ 个 feature flag 通过 Bun plugin 实现死代码消除
3. **三层上下文压缩**: 微压缩 -> 会话记忆压缩 -> 完整压缩
4. **多智能体 Swarm**: 团队创建、消息通信、Worktree 隔离
5. **多云支持**: Anthropic / AWS Bedrock / Azure / Google Vertex
6. **完整可观测性**: OpenTelemetry traces + metrics + logs
7. **MCP 协议集成**: Model Context Protocol 工具扩展
8. **文件系统记忆**: 基于文件的持久化记忆系统
